## 1. The project

**CivCentral** (civcentral.com) is the central hub and lore archive for
**Minecraft civilization events** — large multiplayer roleplay events where
players build nations, fight wars, and generate emergent history. The site
documents that history (a wiki), and is also a community hub: events, ratings,
discussion, and Discord integration.

Guiding principle / tagline: **"Every telling has a home."** We preserve every
player's version of history side by side — an archive, not a single source of
truth.

We're rebranding from the old name "WikiCiv" to **CivCentral**, so this is a
fresh primary identity.

## 2. Audience & feel

- **Who:** Minecraft players and civ-event communities — Discord-native, mostly
  teens to 20s, game-literate.
- **Tone:** game-native but **trustworthy and archival** — think "official
  records office for a game world." Confident, clean, a little heraldic.
  **Not** childish, not clip-art, not a generic tech startup.
- **Three words:** *civilization · central/hub · heritage.*

## 3. What I need (deliverables)

1. **Primary logo** — horizontal lockup: icon + the wordmark "CivCentral".
2. **Icon / app mark** — the symbol alone, square, works as a favicon down to
   16px and as an app icon.
3. **Discord server icon** — circular crop, bold and readable as a small round
   avatar.
4. **Variants:** full-color, **one-color/monochrome**, and versions that work on
   both **light and dark** backgrounds.

## 4. Direction

I've explored five directions (see the reference SVGs). Use them as a starting
point — feel free to combine or push past them:

1. **Voxel tile** — pixel "C" on a rounded tile (most Minecraft-native).
2. **Compass hub** — spokes converging on a center ("all roads meet here").
3. **Iso ziggurat** — an isometric block tower (a built civilization).
4. **Civic crest** — shield + castle (heraldic archive; great for the Discord icon).
5. **Hex cube** — an isometric block that reads as a hexagon badge (modern, scalable).

**My lean:** a clean, modern emblem (direction 5) as the primary mark, with a
more heraldic crest (direction 4) for the Discord server icon. A subtle nod to
Minecraft's blocky/isometric world is welcome; an obvious, on-the-nose
"Minecraft block" is not required.

## 5. Color palette (starting point, not a cage)

- Emerald `#10B981`, light `#34D399`, deep `#047857`
- Gold accent `#FBBF24`
- Ink `#0F172A`

Open to a refined palette if you have a stronger idea — emerald + gold is the
current direction (growth/heritage), but show me your take.

## 6. Hard requirements

- **100% original artwork.** Do **not** use Mojang/Minecraft trademarks, the
  official logo/font, real Minecraft block textures, or any copyrighted/stock
  assets. A *stylistic* nod (blocky, voxel, isometric) is fine; literal Minecraft
  IP is not. This protects both of us.
- Must stay legible and recognizable in **pure black-and-white** and at **16px**.
- The icon must work **standalone** (without the wordmark).

## 7. Technical specs

- Final files in **vector** (`.svg` + source `.ai`/`.fig`), plus exported
  **PNG** at 1024, 512, 192, 64, 32, 16 px, on transparent backgrounds.
- Wordmark: please state the typeface used, or provide outlined vectors. A
  geometric, slightly condensed sans is the current vibe.
- Deliver light-bg and dark-bg versions of each.

## 8. Please avoid

- Generic "AI sheen," heavy bevels, drop shadows, or 3D glossiness.
- Overly detailed marks that turn to mush at small sizes.
- Anything that copies an existing game/community logo.
